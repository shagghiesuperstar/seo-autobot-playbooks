# Intake interview (full)

> Part of ULTIMATE SEO/GEO/AEO/AIO AUTOBOT. Generated from the Search Ops export (`onboarding.interview`). Skill names are mapped to staged slugs.


## Rules
1. One question at a time; wait for the answer before asking the next.
2. Don't move on until the answer is usable; a vague answer is a follow-up, not a pass.
3. Mark what you could not learn as unknown, and never fill an unknown with a plausible number.
4. Never invent a competitor, a benchmark, a price, a ranking, or a customer.
5. Keep the operator's private details out of any field a stranger could read.
6. Stop at every approval gate: directory submission, checkout, outreach send, public reply.
7. Only ask a question that would change what you run next — otherwise decide and go.
8. Part `agent` is asked only when agents, assistants buying or booking, MCP, or security are in scope (q6 says "invisible to AI assistants", q26 says yes, the routing lands on W9, or the operator asks for an audit). Ask q30 and q32 first; the rest only when they change the audit. Never re-ask what another part already answered: q1 (site), q17 (who changes the site), q26 (feed), q29 (crawler stance), and q10/q18 (delivery, cadence) are reused as-is.
9. Never collect a password, API key, or card number in chat. A key the audit needs is set as an environment variable by the operator.
